# Changelog

## 1.1.0 — 2026-09-07

- **Stop & save report** — stopping a run finishes the current page, then generates a partial HTML report from collected data
- Partial reports are clearly labeled (never a bare GO/NO-GO) and available in the popup
- **Stop without report** option for users who want to discard the deliverable
- Resume research from the last completed step after a stop
- Report history (last 5) in the popup; storage quota guard for very large HTML
- In-extension report viewer + download for full and partial reports

## 1.0.0 — 2026-09-06

- Initial public release of **EtsyHunt**
- Local-first 4-step Etsy niche research pipeline
- Popup UI for seed input, product-type filter, progress, activity log, and settings
- HTML niche reports downloaded to your machine
- Free and open source (MIT)
